Problem: Client was using display method provided by the original object
but that method had access control,caching and lazy loading. 

Solution: We wrapped original object into a proxy object. It : 
    1. Deligates work to original object only if access is allowed
    2. Caches the original object instead of creating new for every method call
    3. Loads only when required instead of loading everytime when system loads into system
